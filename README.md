# Sai Preethi Bandi — Portfolio

A responsive, static portfolio website for GitHub Pages, inspired by the visual structure of `saipavantejak.github.io` and customized using Sai Preethi Bandi's supplied resume.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive dark theme and visual styling
- `script.js` — mobile navigation, reveal animations and active section navigation
- `assets/Sai-Preethi-Bandi-Resume.pdf` — resume download (if included)

## Publish with GitHub Pages

1. Create a GitHub repository named **`YOUR-GITHUB-USERNAME.github.io`**.
2. Extract this ZIP file.
3. Upload the contents of the extracted folder to the **root** of that repository. Make sure `index.html` is at the repository root, not inside another nested folder.
4. Commit and push to the `main` branch.
5. In GitHub, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the deployment to finish. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/`.

If you want to publish under a project repository instead, the URL will usually be `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`.

## Personal details to verify before publishing

- Confirm that the LinkedIn URL in `index.html` is the correct public profile URL.
- Confirm that the current role, dates and locations are accurate and that you are comfortable publishing them.
- The supplied resume lists professional experience and education but no standalone projects, so this portfolio uses experience-based engineering focus cards rather than inventing projects or metrics.
- The portfolio currently links to the resume PDF included in `assets/`.

## Local preview

Open `index.html` in a browser. No build tools, package installation or framework are required.
